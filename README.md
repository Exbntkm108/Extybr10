Получение API-ключа


    Перейдите на сайт exchangerate-api.com.

    Зарегистрируйте бесплатный аккаунт.

    После регистрации вам будет предоставлен API-ключ.

    Скопируйте этот ключ и вставьте его в переменную API_KEY в начале Python-скрипта (API_KEY = "ВАШ_API_КЛЮЧ").


Описание

"Currency Converter" — это GUI-приложение, разработанное на Python с использованием tkinter и внешнего API exchangerate-api.com для получения актуальных курсов валют. Приложение позволяет пользователям конвертировать сумму из одной валюты в другую. Оно также сохраняет историю всех произведенных конвертаций в файл conversion_history.json и отображает ее в таблице. Проект управляется с помощью Git.

Примеры использования


    Запуск:


        Сохраните код как currency_converter.py.

        Убедитесь, что установлен Python и библиотеки requests (pip install requests).

        Важно: Замените "YOUR_API_KEY" в коде на ваш реальный API-ключ.

        Откройте терминал, перейдите в директорию с файлом и запустите:
        bash
        python currency_converter.py

        При первом запуске будет создан .git репозиторий и файл .gitignore.

    Конвертация валют:


        Выберите валюту, из которой хотите конвертировать (поле "Из валюты").

        Выберите валюту, в которую хотите конвертировать (поле "В валюту").

        Введите сумму для конвертации в поле "Сумма". Сумма должна быть положительным числом.

        Нажмите кнопку "Конвертировать".

        Результат конвертации отобразится в поле "Результат".

        Информация о конвертации будет добавлена в таблицу "История конвертаций".

    Просмотр истории:


        Таблица "История конвертаций" показывает время, валюты (из и в), исходную сумму и результат конвертации. Новые записи добавляются вверху.

    Git:


        Скрипт автоматически инициализирует Git-репозиторий при первом запуске.

        Файлы conversion_history.json и __pycache__ добавлены в .gitignore, чтобы не сохранять историю и временные файлы в Git.

        Для выгрузки проекта на удаленный репозиторий (например, GitHub):
        bash
        git add .
        git commit -m "feat: Currency converter with API, history, and git"
        git branch -M main
        git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
        git push -u origin main
